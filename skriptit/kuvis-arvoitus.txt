KUVISLUOKAN ARVOITUS (prinsessa sonan pakohuone) — vastaus: SATEENKAARET  (12 kirjainta, 7 eri)

TARINA
Kuvisope: "Tunti ei lopu ennen kuin maalaukset on valmiit!" ...ja lähti vessaan.
Maali on loppu. Kun istut penkille, ope kuiskaa kaksi väriä: sekoita ne päässäsi.
Opettajan pöydällä on lappu (väriavain). Kirjaimet penkkien järjestyksessä = salasana.
(Linkki aiempaan: Petterin kuvistyö oli "sateenkaari 7 värillä".)

PENKIT (järjestys: rivi 1 vasemmalta oikealle, sitten rivi 2) — kuiskaus kun istuu
 1. sininen + sininen        -> sininen   -> S
 2. keltainen + punainen     -> oranssi   -> A
 3. keltainen + sininen      -> vihreä    -> T
 4. punainen + sininen       -> violetti  -> E
 5. sininen + punainen       -> violetti  -> E
 6. punainen + punainen      -> punainen  -> N
 7. keltainen + keltainen    -> keltainen -> K
 8. punainen + keltainen     -> oranssi   -> A
 9. keltainen + punainen     -> oranssi   -> A
10. oranssi + sininen        -> ruskea    -> R
11. punainen + sininen       -> violetti  -> E
12. sininen + keltainen      -> vihreä    -> T

OPEN LAPPU (väriavain) — laita tämä pelaajan nähtäväksi (pöytä/seinä/kuiskaus)
 sininen = S
 oranssi = A
 vihreä = T
 violetti = E
 punainen = N
 keltainen = K
 ruskea = R

LOPPU: ovella / lapun luona sano "sateenkaaret" -> teleport välitunnille.
WIRED (per penkki): kun käyttäjä istuu penkille -> näytä viesti (kuiskaus) "väri + väri".
Varasanat samaan tapaan: SIVELLINVETO, VESIVÄRIKUVA, ABSTRAKTINEN, VAPAUTUMINEN (kaikki 12 kirjainta).
